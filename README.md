# ATELIER LIGHT

Демонстрационный интернет-магазин дизайнерского освещения для портфолио. Сайт сделан на HTML, CSS и JavaScript без сборки и серверной части.

## Как открыть

Откройте `index.html` в браузере. Для проверки через локальный сервер в терминале VS Code можно выполнить:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Что работает

- Каталог из восьми демонстрационных товаров с фильтрами, поиском и сортировкой.
- Карточки товаров и корзина с изменением количества. Корзина сохраняется в браузере через `localStorage`.
- Путь оформления демозаказа. Данные формы никуда не отправляются, оплата не проводится.
- Адаптивная верстка, клавиатурная навигация и учет настройки уменьшения движения.
- Плавное появление блоков при прокрутке вниз и повторное появление при возвращении вверх.

Цены, названия и описания товаров вымышлены. Фотографии локально сохранены с Unsplash; ссылки на исходные страницы указаны в [источниках фотографий](credits.html).

## Структура

- `index.html` — страница магазина.
- `style.css` — оформление и адаптивная верстка.
- `script.js` — каталог, фильтры, корзина и демозаказ.
- `assets/images/` — фотографии.
- `CASE-STUDY.md` — описание проекта для портфолио.
- `previews/` — снимки главной страницы и каталога на компьютере и телефоне.

Для настоящих продаж потребуются реальные товары и цены, серверное хранение заказов, доставка, оплата и юридическая информация.
