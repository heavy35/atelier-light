# ATELIER LIGHT — product brief

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript. This is a portfolio concept, so it can be hosted on GitHub Pages.

## Users
People browsing decorative lighting for a home. This audience is an assumption for the concept project.

## Product Purpose
Demonstrate an end-to-end small-shop experience: discover a lamp, compare options, inspect a product, add it to a cart, and complete a demo checkout.

## Capabilities and Constraints
- Product names and prices are illustrative.
- Cart state persists locally in the browser.
- Checkout never charges money or sends personal data to a server.
- The site should work on desktop and mobile, with keyboard-accessible controls.

## Evidence on Hand
No real merchant, product inventory, customer reviews or fulfilment information was provided. Photography is licensed stock imagery used as visual stand-ins; sources are recorded in `assets/images/sources.json`.
